🔄 3. De Agent Pipeline (kern van de app)

Wanneer een gebruiker iets typt, doorloopt runAgent() in src/ai/agent.ts deze fases:

User input
  ↓
1. UNDERSTANDING     → callChatAI() → intent (build/edit/quick-edit/discuss)
  ↓
2. PLANNING          → createPlan() → AppPlan (screens, components, data, logic)
  ↓
3. UI AGENT          → generateUI() → enriched screens met componenten
  ↓
4. BACKEND AGENT     → generateBackendSchema() → database schema
  ↓
5. ARCHITECTURE      → generateArchitecture() → blueprint (components/pages/api/models)
  ↓
6. BUILDING          → buildDirect() → streamt HTML via generate-app edge function
  ↓
7. TESTING           → runTests() → checkt structuur, interactiviteit
  ↓
8. SCORING           → scoreApp() → 0-10
  ↓
9. CRITIC + FIX LOOP (max 5x, tot score ≥ 8)
   - critic-ai analyseert
   - issues worden gefixt via buildDirect()
   - opnieuw testen en scoren
  ↓
10. MEMORY + VERSIONING → opslaan in localStorage
  ↓
Done!
